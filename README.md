# URBAN RUN: LONDON ENDS — Collection 01

First-pass original, procedural Three.js streetwear prototypes (not branded replicas): Urban Ridge 95, Urban Current 110, Urban Circuit Tech.

## Run on Android

Publish this repository with GitHub Pages: Settings → Pages → Deploy from branch → main → /(root). Open https://claritybracks-sketch.github.io/urban-run-london/.

Requires an internet connection for the Three.js module hosted by esm.sh. If the browser shows a blank screen, ensure JavaScript and WebGL are enabled and try Chrome.

## Code structure

- index.html: responsive interactive 3D showroom
- src/streetwear.js: reusable mesh factory functions

The meshes are low-detail placeholders for concept validation, not photorealistic final assets. No third-party branding, logos or copyrighted textures are included.
